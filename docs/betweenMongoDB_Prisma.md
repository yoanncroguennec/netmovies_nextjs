Prisma s’occupe de :

*   Valider les types,
*   Générer les requêtes Mongo optimisées,
*   T’offrir une **autocomplétion TypeScript** ultra pratique,
*   Proposer une API plus clean que le driver natif.

| Aspect | MongoDB direct | Prisma avec MongoDB |
| --- | --- | --- |
| Accès bas niveau | ✅ complet | ❌ abstrait |
| Validation des données | ❌ manuelle ou via Mongoose | ✅ via `schema.prisma` |
| Types & autocomplétion | ❌ (à la main) | ✅ TypeScript-friendly |
| Rapidité & flexibilité | ✅ plus libre | ⚠️ un peu plus strict |
| Relations entre modèles | ❌ complexes à gérer | ✅ simplifiées (mais limitées avec Mongo) |
